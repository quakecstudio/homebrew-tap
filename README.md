# homebrew-tap

Homebrew tap for [QuakeC Studio](https://www.quakecstudio.com), a modern IDE for QuakeC.

```bash
brew install --cask quakecstudio/tap/quakec-studio
```

The cask lives in `Casks/quakec-studio.rb`. The release workflow of [quakecstudio/editor](https://github.com/quakecstudio/editor) rewrites it for each release and pushes it here with a deploy key.
